## 浏览器验证

测试页：`/tests/browser.html?width=1280` 与 `/tests/browser.html?width=390`。在内置真实浏览器中执行，分别使用 **1280×844、390×844 的被测 iframe 视口**，两种视口各12/12通过，见 [桌面输出](../evidence/browser-desktop-results.txt) / [窄屏输出](../evidence/browser-mobile-results.txt)。这是浏览器响应式检查，不是物理手机或 Safari 的兼容性结论。

- 12 项集成检查包括默认经典/无敌关闭、四角色选择、键盘移动与真实命中、跳踢和纵深隔离、死亡与跳跃键复活、双人独立操作及友伤模式、暂停/失焦清理、改键冲突/保存、必杀代价、高血量与无敌、Boss/转场/续关/结局、八关绘图与窄屏布局。
- Boss/结局检查使用诊断夹具定位场景；不能将它算成人工完整通关。全流程无敌输入测试另在 Node 中执行。
- 直接通过浏览器键盘操作验证过 P1/P2 移动、攻击、跳跃、必杀和 Esc 暂停。诊断快照见 [记录](../evidence/native-keyboard-state.json)；截图只能证明捕获时的画面，不能单独证明完整战斗正确。
- 390 像素视口检查无水平溢出、触屏方向和动作键可见；浏览器实际点击右移/跳跃/必杀按钮，位置变化且必杀消耗1能量，见 [状态](../evidence/mobile-touch-state.json)。输入模块验证多指组合/取消释放。尚未用物理手机实测多点触控，也未验证所有浏览器的音频/全屏策略。

最终截图：[桌面游戏](../evidence/gameplay.png)、[手机布局](../evidence/mobile-layout.png)、[四龟动作](../evidence/character-sheet.png)、[人物与敌人](../evidence/characters.png)。本轮最终游戏页、测试页和动作页的控制台 warn/error 均为空，见 [控制台记录](../evidence/console.json)。

## 原版精度仍存在的具体差距

1. **资料覆盖未达到全片逐帧。** 已读北美说明书，并在一段覆盖完整路线的录像中抽查八关、主要 Boss 和结局；没有连续完整观看64分钟、全动作覆盖或ROM修订号确认。双人第二录像只有作者章节可读。日版FC地区差异尚未逐项核对。
2. **战斗常量尚未标定。** 角色范围/周期/伤害与 Boss HP引用可追溯的第三方实测报告；最大能量8、移动/跳跃曲线、碰撞框、纵深容差、硬直22帧、受击保护88帧、复活保护150帧等是重建值。双人A/B与25,000加命按说明书处理，手册与部分攻略的矛盾尚未通过同版本实机消解。
3. **完整布阵和场景交互尚未逐波复刻。** 八关顺序和各自场景/机关已实现，但波次数量、出生位置、锁屏点、地图长度、披萨分布、机关窗口仍为重建。冲浪/升降段当前在清敌间隔自动推进；未证明等同原版持续卷屏或垂直平台节奏。地铁列车交互、生产线完整机关及救April过场尚不完整。
4. **Boss行为仍有简化。** Krang分体上身锤击尚缺；当前分体激光/下身踢击与合体循环未经原版逐帧对照。Tokka的抓握16帧/抛投40帧、灯牌伤害和盾覆盖范围为重建；Rocksteady只能从录像检查帧确认持枪腾空，新增跃起与射击时序不能称为原版定值。其余Boss的分支选择、距离触发、单/双人差异仍需测量。
5. **平衡、素材与设备覆盖有限。** 全八关尚未完成经典模式人工通关和平衡校准；图像、动作与合成音效是原创表达，无原版音乐/语音。移动设备仅浏览器窄视口验证，未做物理手机与跨浏览器矩阵。

上述差距明确保留；本交付是**可玩的八关独立重建，尚未达到同版本逐帧和完整布阵复刻**。后续原版一致性验收应记录固定版本的输入、脚底坐标、动作开始/命中/结束帧，并报告逐项误差；不能只追加本地测试后便删除差距。
