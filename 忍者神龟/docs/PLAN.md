# 玩法重建工作记录

版本基准：北美 NES-T3-USA，Teenage Mutant Ninja Turtles III: The Manhattan Project (1992)。日版同作为 FC《T.M.N.T. II: The Manhattan Project》(1991)，当前不宣称逐项重现日版差异。

1. 读取手册与完整流程录像来源，记录证据等级和不确定项。
2. 建立与 DOM/Canvas 无关的固定步长模拟；先完成海滩到 Rocksteady，再贯通全部八关。
3. 原创绘制、Mac 键盘/改键/触屏、单人和双人界面集成。
4. 规则测试、八关推进测试、实际浏览器输入/截图/控制台/窄屏验证，修复缺陷。
5. 交付启动入口、证据对照表、测试结果和具体精度差距；不推送、不部署。

## 边界

所有产物仅在本目录。仓库有其他游戏的并行工作区修改；本任务仅写入“忍者神龟”，不改动或回滚兵蜂、魂斗罗。不下载 ROM、原作图像或原作音频。Canvas 图形和音效用原创代码生成。不得把重建常量表述为已测原版数据，不把本地测试当作原版一致性证明。

## 模块契约

- `src/core.js` / `src/content.js`：60 Hz 固定步长，纯 JS，无 DOM；屏幕逻辑 960×540，地面纵深 y 290..465，跳跃高度 z 独立。
- `src/input.js`：映射为每玩家的 left/right/up/down/attack/jump/special 布尔值；模拟负责按键边沿。暂停和失焦时清空输入。
- `src/renderer.js`：只读取模拟状态；不得改变碰撞或胜负规则。
- `src/app.js`：菜单、选择角色、改键、暂停、继续和 DOM HUD。
- `tests/`：Node 内置 test；浏览器测试另记人工/自动证据边界。

当前状态：可玩重建与本轮人物重画已交付。四龟、Foot和人形Boss采用原创小像素、圆润轮廓和独立动作；41项Node回归、13个JS文件检查、1280/390两种视口各12项浏览器检查通过，真实键盘/触屏点击、截图和控制台已检查。遮罩缓存、短按丢失、冰冻/变形恢复、借命角色冲突等问题已修复。
