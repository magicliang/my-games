# 忍者神龟 · 曼哈顿计划

**启动游戏：** 在这个目录运行 `npm start`，打开 <http://127.0.0.1:4175>。不需要 `npm install`。Mac 也可以双击 `开始游戏.command`；需要已安装 Node.js 20 或更新版本。

```sh
cd /Users/magicliang/Desktop/Programming/git/my-games/忍者神龟
npm start
```

这是以 **NES-T3-USA，1992 北美版《Teenage Mutant Ninja Turtles III: The Manhattan Project》** 为基准的独立玩法重建。日版 FC 同作编号为 II；没有混入街机、SNES《Turtles in Time》或 DOS《Manhattan Missions》。以可玩的八关流程为交付目标，不能把此实现称为逐帧准确的模拟器或原版移植。

## 开始游玩

1. 选择玩家 1 的神龟；双人时切换“玩家 2”再选另一只。
2. 选择单人、双人 B（无友伤）或双人 A（有友伤）。默认单人经典，**无敌默认关闭**。
3. 点击“开始行动”或按 Enter。先消灭当前编队，再向右推进；每关打败末尾 Boss 后进入下一关。
4. 倒下后用移动左右换龟，按跳跃确认复活；也可点击角色卡再按跳跃。双人一方耗尽命时可按跳跃向仍有备用命的同伴借命。

| 操作 | 玩家 1 | 玩家 2 |
| --- | --- | --- |
| 上 / 下 / 左 / 右 | W / S / A / D | 方向键 |
| 攻击 | J | U |
| 跳跃 / 确认复活 | K | I |
| 必杀 | L | O |
| 暂停 / 继续 | Esc（共用） | Esc（共用） |

- **投掷：** 下 + 攻击；**飞踢：** 起跳后按攻击。连按攻击衔接连续普攻，不添加无依据的三段加伤。
- **必杀：** 独立键，或同时按攻击 + 跳跃。消耗 1 能量单位，最后 1 单位不再扣。四龟的必杀动作不同。
- **改键：** 右上“改键 / 设置”。用物理键位识别，检查两名玩家全部动作的冲突，不使用小键盘。Enter/Esc 保留。设置仅保存于本机浏览器。
- **触屏：** 窄屏自动显示方向、攻击、跳跃、必杀；可多指同时操作。顶部“控制”选择玩家。双人同机推荐普通键盘；触屏控制可交替切换两人，不是两个独立触屏手柄。
- **失焦：** 自动暂停并释放所有输入；必须主动继续，避免切回时意外挨打。

## 模式与角色

经典使用 8 单位能量，高血量使用 32，无敌模式忽略敌人和环境伤害；这些最大能量值是重建设置，未独立测量原版。必杀仍保留能量代价。改模式在新一局生效，不会默默改动正在进行的游戏。

| 神龟 | 普攻 / 必杀 |
| --- | --- |
| Leonardo 达芬奇 | 双刀，中距离；旋风双刀可环绕打击 |
| Raphael 拉斐尔 | 双叉，出手周期最短；水平钻击 |
| Michelangelo 米开朗基罗 | 双节棍；袋鼠踢，单次必杀伤害最高 |
| Donatello 多纳泰罗 | 长棍，普攻距离最远；前空翻打击 |

## 代码结构

`src/core.js` 是固定 60 Hz 的纯模拟，`src/content.js` 集中来源参数与重建数据；`src/renderer.js` 只读状态绘图，`src/actors.js` 绘制原创像素人物和动作，`src/input.js` 处理键盘/触屏，`src/app.js` 管理界面与固定步长循环。切换渲染表现时不需要修改命中规则。

若 4175 端口被占用，可运行 `PORT=4176 npm start` 并打开对应地址。直接双击 `index.html` 会受浏览器 ES 模块本地文件限制，请使用上述本地入口。
