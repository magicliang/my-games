# 魂斗罗：丛林突击 3D 说明书

## 启动游戏

在本目录执行：

```bash
npm install
npm run dev
```

浏览器打开终端显示的地址，默认是 `http://127.0.0.1:5173/`。

生产版本：

```bash
npm run build
npm run preview
```

## 操作

| 操作 | 键位 |
| --- | --- |
| 前后左右移动 | `W` `A` `S` `D` |
| 跳跃 | `空格` |
| 瞄准 | 移动鼠标 |
| 连续射击 | 按住鼠标左键或 `J` |
| 暂停/继续 | `Esc` |
| 重新开始 | 结算页点击“重新出击” |

手机和平板会显示触屏方向、跳跃和射击按钮。桌面键鼠体验更完整。

标题页输入经典秘籍 `↑ ↑ ↓ ↓ ← → ← → B A Enter`，开始行动时会获得 30 条命。

## 任务目标

从西侧丛林向东推进，经过浅水区和两座爆破桥，抵达终点堡垒。堡垒核心带有护盾，必须先摧毁屋顶狙击手与左右两门守卫炮，再攻击中央核心。

## 规则

- 初始 3 条命。敌弹命中会损失 1 条命，随后获得约 3 秒无敌时间。
- 阵亡后从最近的 0 米、50 米或 100 米检查点复活，武器恢复为普通步枪。
- 浅水可以进入，但移动速度会下降；桥面爆炸遵循红白机版的无伤规则。
- 消灭敌军、命中目标和拾取武器都会增加得分。
- 摧毁终点核心即通关；生命耗尽则任务失败。

## 武器

| 标记 | 武器 | 特点 |
| --- | --- | --- |
| `R` | 快速步枪 | 射速最高，适合压制杂兵 |
| `S` | 散弹枪 | 一次发射三枚弹丸，近距离覆盖面大 |
| `L` | 激光枪 | 弹速快、单发伤害高，适合攻坚 |

## 关卡说明

本作以经典丛林第一关为结构参考：丛林起点、浅水、两座爆破桥、高台火力点、武器升级和终点堡垒。所有 3D 模型、界面、音效与敌人编排均为本项目原创实现，没有复制原游戏贴图、音乐或程序代码。
