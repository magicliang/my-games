# 魂斗罗：丛林突击 3D

原创 FC 风格像素人物、Three.js 三维场景的单人横版丛林第一关：方向射击、伏地、跳台、游泳、爆破桥与堡垒核心。战斗固定在同一平面，默认经典模式、无敌关闭。

```bash
npm install
npm run dev
```

打开终端给出的本地地址，默认 [http://127.0.0.1:5173/](http://127.0.0.1:5173/)。`A/D` 或左右方向键移动，`J/Z` 射击，`K/空格/X` 跳跃；标题页和暂停页的“操作与设置”支持改键和触屏。
