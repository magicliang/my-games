# FC 初代《兵蜂》机制依据与验收边界

目标版本为 1986 年 Family Computer《TwinBee》，不是街机版、3D Classics 或续作。核查日期：2026-10-25。本文件区分已找到依据的规则和仍需实机校准的数值；它不是“逐帧完全复刻”的证明。网页素材、声音为项目自行绘制和合成。

## 2. 可作为验收依据的规则

### 攻击、受伤与复活

- FC 原按键 **B 对空、A 对地**。对空弹攻击空敌、云、铃与 Boss；对地弹依赖前方瞄准区，在发射时锁定范围内地物。不是随处投下的大范围清屏炸弹。
- FC 的地面投弹为单发；敌弹首次击中无护盾机体会同时失去双臂，随后无法投弹。无臂再次中弹或直接撞空敌会损失一机。左右臂分别受损是街机规则。
- 每条命只有一次救护车机会；丢臂后出现，碰到修复，漏掉不会重复派出。死亡后新机重新获得这个机会。
- FC 单人死亡在当前进度复活，全部强化清零。没有找到回滚到关卡检查点的 FC 依据。Boss 已承受伤害保留。
- 地面物炸毁后产生的奖励，由飞机与奖励位置重叠拾取；不需要继续投弹。测量记录明确描述“出た所に重なると取れます”。

### 铃铛与装备

| 铃铛 | FC 效果 | 约束 |
| --- | --- | --- |
| 黄 | 连续收取奖励 500、1,000、5,000、10,000，此后保持 10,000 | 漏铃重置；未漏铃的连分跨关保留 |
| 蓝 | 提升机体移动速度 | 原版速度上限尚未核实，不能把街机的 16 段直接当作 FC 结论 |
| 白 | 并排双炮 | 不能叠加三向弹；可配合分身；测量记录称已有双炮或三向弹时第9击保持黄色 |
| 红白闪烁 | 两个延时跟随的分身，与本体一起射击 | 仅单人；停下会逐渐与本体重合；不与护盾、三向弹共存 |
| 红 | 防护罩，抵消一定数量的弹击/碰撞 | 与分身互斥；敌机碰撞消耗大于子弹 |

击中特殊颜色铃后再打一发就回黄，需继续打到下一特殊命中点；不是每五发稳定升级后保持颜色。过度射击会变为有碰撞伤害的蜂敌，仍可被射杀。先生成两种冲突铃再收取，也不能同时获得护盾与分身：FC 保留先获得的装备，后一铃按黄铃计分。持分身时不再产生红铃和糖果；持护盾时不再产生分身铃。分身状态不是两个永远固定在左右侧的炮台。

### 地面奖励、计分与双人

| 项目 | 规则 |
| --- | --- |
| 糖果 | 单人三向弹；与双炮互斥，分身状态不可取得三向能力。按 Select 收取可改为左横、前方、右横方向，这是附加技巧。 |
| 水果 / 牛奶 | 水果 100 或 500 分；牛奶增加一机。 |
| 星 | 清除画面普通空敌；不能视作直接杀 Boss 的道具。是否以及如何清敌弹需要逐帧核对，当前测量记录报告会清。 |
| 初始残机和分数奖命 | 初始 3 机；50,000 分首次奖命，此后每 150,000 分一次，至 1,000,000。对应阈值 50,000 / 200,000 / 350,000 / 500,000 / 650,000 / 800,000 / 950,000。 |
| 单个击毁分数 | 空敌 100，地敌 500，Boss 10,000，蜂敌 15,100；均来自官方 VC 手册。 |
| 双人合体 | 横向牵手为 Fire 强弹，纵向接触为 Star 四方向散射；FC 没有街机的 Miracle Ball。分身及糖果是单人机制。 |

### 关卡与 Boss

FC 第五关后继续显示 **STAGE 6**，布局回到第一关并提高难度，分数、残机与存活装备应继续保留。三个 FC 游玩来源明确支持这一点：Sanse“2周目以降”、izuito 第五关及 ameblo 通关记录。不要套用“第二至第五关循环”，也不要弹出结束菜单后把玩家初始化。

| 顺序 | Boss | 能区分它的行为 |
| --- | --- | --- |
| 1 | Onion Head / 洋葱头 | 上半屏横移，可打掉并再生的绕体卫星保护主体，配合扇形射击。 |
| 2 | Parallel Dish / 平行飞碟 | 在上半屏横移和上下运动，释放逐渐变大的圆环；绿环阶段无碰撞伤害，变白后危险。 |
| 3 | Tiger Shark / 虎鲨 | 左右反弹并向下探，青蛙护卫会开火和向下冲锋。 |
| 4 | Claw Device / 巨钳 | 上方横越，出界后从另一边再出现；小护卫绕体旋转并开火/冲出。 |
| 5 | King Spice / 香料王 | 沿画面边缘顺时针运动，释放展开后向下扑的向日葵。 |

Boss 主体沿既定路线移动；发射时子弹/子敌可瞄准玩家当时的位置。不能用同一条正弦横移和同一种扇射替代全部五个 Boss。第 5 关道中明显长于前四关；测量视频第一关开始至 Boss 约 129 秒，第二至四关约 160 秒，第五关约 288 秒。这些只是单次录像时间差，不能当作已经标定的游戏固定计时。

## 4. 回归验收清单

1. **铃铛**：用两颗铃交替命中，验证共享计数；特殊色再中一发变黄；漏任意铃连分归零；过击生成可杀、可撞人的蜂敌；跨关未漏铃继续最高连分。
2. **生存与分数**：带臂中弹同时丢双臂并只派一次救护车；无臂再中弹死亡；死亡后速度、双炮、分身、护盾、三向弹清零；分数一次跨多个奖命阈值不漏发、不重复。
3. **地空与装备**：空气弹打不掉地物；锁定炸弹只炸地面；飞越拾取水果/糖果/牛奶；分身跟随历史轨迹；冲突强化不能叠加或强制换掉已有能力。
4. **关卡与 Boss**：逐个触发五种独特攻击；第2关绿环不伤害、白环可伤害；死亡保留 Boss 伤害；第5关后 Stage6 保留进度并采用第一关布局。
5. **输入与双人**：单人键盘/触控暂停后释放按键；两名玩家有独立输入和存活状态；横纵合体分别触发 Fire/Star；双人不产生单人专用强化。

## 5. 尚不能声称已复刻的边界

原版敌群逐帧出现时间、全部地图坐标、碰撞盒、移动速度曲线、发射上限/冷却、蓝铃上限、护盾判定范围、救护车飞行与修复无敌帧、多铃计数特殊分支、Boss 武器相关耐久，以及高周目的难度曲线都需要原版输入回放或逐帧录像对照。网页自动化通过只能证明本实现遵守自己的规则，不能证明与 FC ROM 完全一致。

## 6. 本次实现与验证记录

当前代码将上面的机制接入可运行引擎，地面奖励按25次循环实现（第6糖果/第15星/第25牛奶）。地物资格仍用全部可击毁目标近似，不能据此宣称原版掉落坐标一致。关卡时长采用129/160/160/160/288秒候选值，既有编队按固定顺序重复；地图和敌群精确时刻仍在待校准范围。无敌/2–99血模式属于用户要求的额外辅助，不是FC规则。

语法与规则/模拟测试见 `npm run check`；真实键盘/触屏和设置回归见 `tests/browser-smoke.mjs`。长时模拟的无敌仅为通关稳定性测试条件，不当作经典模式人工无伤通关证据。
