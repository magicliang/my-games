# FC 机制修复执行清单

目标版本：用户确认的 1986 年 FC 初代《兵蜂》。先完成玩法，再讨论 3D。

1. 核对 FC 说明书和实玩记录；将已确认规则与待逐帧标定参数分开记录在 MECHANICS.md。
2. 修正铃铛、得分、武器、受伤、救护车、单人/双人、循环；把实际运行的模拟代码暴露给 Node 测试，渲染不参与判定。
3. 恢复正交俯视战场和可识别角色；用确定的关卡编队和独立 Boss 行为替换随机奖励与通用弹幕。
4. 运行规则/模拟回归和真实浏览器操作验证；记录精确复刻尚缺的原版帧级证据。

修改前基线：`npm run check` 通过原有 4 个测试；其中旧铃铛测试断言的是错误规则，不将它视为原版依据。

验收：无网络运行；可单双人开局、移动、分离地空攻击、追打/拾取/漏铃、受伤修复、复活、暂停、五 Boss 和带装备/分数的第二周目；正常玩法没有开发测试入口。

执行结果：上列四步已落地，详见 VERIFICATION.md。用户追加的2–99血/无敌辅助、Mac默认空格/F、按键自定义与冲突检查也已接入并验证。精确原版地图和帧时序仍作为明确的校准缺口，不以本地测试替代原版一致性证据。
