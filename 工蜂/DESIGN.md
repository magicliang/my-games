# 兵蜂 FC：当前实现边界

本次目标是 FC 初代机制。事实来源及数值不确定项集中在 `MECHANICS.md`，不混用街机、3DS 或续作规则。

## 模块

- `game-core.js`：铃铛、装备、伤害、计分、奖命、分身历史和周目纯规则；保存五类关卡的编队数据。
- `game-engine.js`：固定 60 Hz 模拟、确定性随机序列、生成/运动/碰撞、五 Boss、双人合体和辅助模式。不依赖 DOM 或渲染。
- `fc-renderer.js`：512×480 正交 Canvas 2D 画面。视觉与判定共用坐标；空中和地面用形状/色彩区分，独立绘制玩家手臂、跟随分身、环弹和锁定准星。
- `game.js`：键盘/多点触控、暂停/焦点管理、辅助和改键设置、声音、HUD；通过累计时间调用固定步长引擎。
- `index.html` / `styles.css`：原有深色机壳和说明书布局，新增战场外的设置区，桌面与窄屏均可访问。

## 行为合同

游戏状态为 ready、playing、paused、stage-clear、game-over。过关短暂停留后自动继续；第五关后进入第六关/第二周目，保留未损失的装备、命数与分数，不再进入一次性胜利菜单。窗口失焦或隐藏会暂停并清空所有按键/触点。

1P 默认空格射击、F投弹，移动用 WASD 或单人方向键；2P 用方向键、逗号和句号。射击/投弹支持改键、冲突检查、取消和本地保存；玩法辅助不默认保存。触屏直接显示动作名称。

经典模式保留 FC 受伤规则。高血量/无敌是用户要求的辅助选项，不作为原版规则：2–99点装甲、每次应用补满；无敌不损伤。模式和每人血量在画面及设置区显示，已出局玩家不因切换模式复活。

## 验证与边界

测试使用真实运行的核心与引擎；长时间模拟可以复现，但不等于原版 ROM 等价。浏览器测试覆盖实际按键、触屏、设置、改键、file://运行及带调试标记的场景。开发状态修改接口仅在 `?debug=1` 中启用。

声音、地形和机体是原创重绘；当前不要求 WebGL。旧 WebGL 渲染器保留作后续3D工作的参考，页面不加载。精确地图、波次与帧级参数以 `MECHANICS.md` 的待校准项为准。
